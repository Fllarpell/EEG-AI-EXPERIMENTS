# Драфт A. Один экран, картинка кода

Этот драфт — то, что сейчас собрано в `neuro_se_experiment/`. Второй драфт (несколько файлов в одном проекте) не реализован: на встрече 09.10 его оставили открытым.

## Что видит участник

1. Три вопроса до заданий: роль (студент / джуниор / мидл), стаж в годах, опыт в языке заданий.
2. Инструкция: в коде возможны баги, ответ — номера строк через запятую, время не ограничено, прокрутки нет. На части заданий над кодом есть подпись об источнике.
3. Картинка кода с номерами строк. Картинка вписывается в фиксированный прямоугольник и не скроллится.
4. Снизу поле ввода и кнопка «Следующее задание». На последнем задании кнопка — «Завершить».
5. Пустой ответ допустим. Так человек может сдать задание, не выдумав строку.

Шильдик рисуется отдельно от картинки. Один и тот же код можно показать с подписью и без, а текст подписи может не совпадать с истинным классом. В демо так сделаны задания `s1_06` (человек, шильдик «Сгенерировано ИИ») и `s1_08` (ИИ, шильдик «Написано человеком»).

Текстовое поле с нумерацией остаётся в программе. В `tasks.json` у задания `"stimulus_type": "text"` вместо `"image"`, и на экран встаёт текст, а не картинка. Ответ, тайминги клавиш и сохранение не меняются.

## Набор на одного человека

Файл `assets/tasks.json` — это один набор, `set_1`, из 10 заданий, как договорились 15.08.

- 8 заданий с багами, 2 без бага.
- Контроль без бага с шильдиком: `s1_09`.
- Контроль без бага без шильдика: `s1_10`.
- Есть лёгкие и сложные. Это задел под sanity check из встречи 09.09: на лёгких нагрузка в среднем ниже, чем на сложных. Софт только записывает `difficulty`. ЭЭГ он не считает.
- Происхождение 5/5: человек и ИИ. Подпись показана на половине и не равна истинному классу на двух заданиях.

Второй и третий наборы — это ещё два JSON той же схемы и смена `TASKS_FILE` в `core/config.py`. Код эксперимента для этого менять не нужно. Python в поле `language` — временная заглушка, пока язык не выбран по статистике GitHub.

Истинные строки багов лежат в `bug_lines` и на экран не выводятся. В `data/trials.csv` пишутся сырой ввод, разобранные номера, попадания, ложные тревоги, пропуски и длительность. Сырой ввод не переписывается: разбор чисел нужен только для счёта «сколько багов нашёл».

Анкета пишется в `data/participants.csv`.

## Чего в этой сборке нет специально

- Имитации ЭЭГ, айтрекера и ЭОГ. На 26.10 это решили навешивать потом. Канал LSL в коде есть и по умолчанию выключен (`ENABLE_LSL = False`).
- Лимита времени.
- Прокрутки.
- Переключения файлов внутри проекта. Это драфт B.

Каждое нажатие в поле ответа пишется с реакционным временем от появления кода. Маркер начала задания ставится сразу после первого кадра с этим кодом.
