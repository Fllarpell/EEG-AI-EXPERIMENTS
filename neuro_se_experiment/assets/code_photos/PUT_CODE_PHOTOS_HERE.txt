Сюда кладутся фотографии кода вместо текстового показа.

1. Положите файл в эту папку, например:
   neuro_se_experiment/assets/code_photos/task_01.png

2. В assets/tasks.json у этого задания замените поля:

   "stimulus_type": "image",
   "image_path": "assets/code_photos/task_01.png"

Картинка встаёт на место текста и вписывается в экран без прокрутки.
Номера строк должны уже быть на фотографии: по ним участник называет баг.

Если stimulus_type оставить "text", на экране будет текст из code_text.
На стартовом экране M — все строки одного цвета, R — каждая строка своего цвета.
На фотографию эта раскраска не действует.
